# Welocome to the club buddy

## Запус проекта

1.  ```bash
    npm install
    ```

````

2. Запуск проекта

```bash
npx expo start
````

## Тестирование

1.  Установите соответствующую с SDK (текущая 56) в проекте версию Expo Go на телефон https://expo.dev/go
2.  Запустите проект через тоннель:

```bash
npx expo start --tunnel
```

3.  После запуска проекта в консоли будет QR code и url, через которые можно будет подключиться с приложения на телефоне.

## Решение проблем

- Очистка кэша Expo
  ```bash
  npx expo start -c
  ```
